# Parcial 2 — Programación Orientada a Objetos

Solución al segundo parcial del curso de Programación Orientada a Objetos. Ejercicio de evaluación que aplica los principios fundamentales de POO en Java.

## Descripción

Implementación de una solución a un problema de diseño orientado a objetos bajo condiciones de evaluación. Aplica los conceptos de encapsulamiento, herencia y diseño de clases trabajados durante el curso.

## Conceptos aplicados

- Diseño y modelado de clases
- Encapsulamiento y control de acceso
- Relaciones entre objetos
- Lógica de negocio orientada a objetos

## Tecnologías

- Java

## Cómo ejecutar

```bash
git clone https://github.com/Sebasve0810/parcial-2-taller.git
cd parcial-2-taller
javac "parcial 2"

```
